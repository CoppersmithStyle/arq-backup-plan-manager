## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Plan Organizer** | Manage backup plans with source, destination and schedule |
| **Destination Manager** | Track cloud and local backup destination health |
| **Restore Points** | Browse available restore points per backup plan |
| **Storage Monitor** | Track storage usage per destination with quota alerts |
